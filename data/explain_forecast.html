미래소요 예측 — 알고리즘 설명

1. 무엇으로 배우나

지금 사용 중인 데이터(기본 내장 가상데이터, 또는 ③ 탭에서 만들거나 불러온 데이터)의 청구일자를 이용합니다. 데이터 기간의 모든 평일마다, 보급기지와 수령지역 조합별로 그날 청구가 몇 건이었는지 세어 학습 자료를 만듭니다(청구가 없던 날은 0건).

2. 날짜에서 뽑는 정보

  • 요일(월~금): 월요일에 많고 금요일에 적은 경향을 배웁니다.
  • 계절: 1년 중 몇 번째 날인지를 원 위의 위치로 바꿔(12월 말과 1월 초가 이어지도록) 계절 흐름을 반영합니다.
  • 분기말 여부: 3·6·9·12월 20일 이후인지.
  • 보급기지·수령지역: 기지·지역마다 특징을 숫자 몇 개로 요약해(전문용어로 '임베딩') 지역별 차이를 배웁니다.

3. 지역·기지별 비율을 정하는 모델

위 정보를 넣으면 그날 해당 기지→지역 청구 건수를 내는 작은 다층 신경망(MLP)입니다. 입력값을 두 번의 중간 계산 단계를 거쳐 하나의 숫자(건수)로 바꿉니다. 중간에는 값의 크기를 고르게 맞춰 학습을 안정시키는 단계와, 특정 계산에만 기대지 않도록 일부를 잠깐 끄고 연습하는 단계가 들어 있습니다. 학습은 예측과 실제의 차이가 줄어들도록 가중치를 조금씩 고치는 일을 자료 전체에 대해 15번 반복합니다.

4. 같은 결과, 자동 재학습

  • 시작값을 고정(시드 42)해서 같은 데이터는 언제나 같은 결과가 나옵니다.
  • 데이터를 바꾸면(③ 탭 '이 데이터를 ①·②에 사용') 자동으로 다시 배웁니다. 같은 데이터로 배운 결과는 저장해 두었다가 다시 씁니다.

5. 날짜별 총 건수: 모델 4종 비교 (실제 사용)

날짜별 총 청구 건수는 아래 네 모델로 예측하고 성적을 비교합니다. 모두 프로그램 안에서 직접 구현했고 외부 인공지능 라이브러리는 쓰지 않습니다.

  • 입력: 지난 20 평일(약 4주)의 하루 건수와 각 날의 요일·계절·분기말 정보, 그리고 예측하려는 날의 날짜 정보. 주말은 청구가 없어 뺍니다.
  • 출력: 그날 하루의 총 건수. 여러 날은 하루씩 예측해서 그 값을 다음 날 입력으로 이어 붙입니다.
  • 성적 매기기: 데이터의 마지막 40 평일은 학습에 쓰지 않고 시험 문제로 남겨 둔 뒤, 하루 앞 예측이 실제와 얼마나 다른지 잽니다.
    • 평균 절대 오차(MAE): 하루 예측이 실제와 평균 몇 건 차이 나는지.
    • 평균 제곱근 오차(RMSE): 크게 틀린 날에 벌점을 더 주는 오차.
    • 둘 다 작을수록 좋습니다. 화면의 ★최우수는 MAE 기준이며 기본으로 선택됩니다.
  • 지역·기지별 숫자: 고른 모델이 낸 날짜별 총 건수를 3번 모델이 낸 기지×지역 비율로 나눕니다.
모델어떻게 보나장점단점
다층 신경망(MLP)지난 20일 숫자를 한 줄로 펼쳐 한꺼번에 계산가장 단순하고 빠름날짜 순서를 따로 고려하지 않음
순환 신경망(RNN·GRU)하루씩 차례로 읽으며 기억을 갱신, 마지막 기억으로 예측순서와 쌓여 가는 흐름을 반영차례로 계산해 느리고, 아주 긴 기간은 잘 기억 못 함
합성곱 신경망(1D CNN)5일(1주) 창을 밀어 가며 짧은 반복 무늬를 찾음주간 반복 같은 짧은 패턴에 강하고 빠름먼 과거는 잘 반영하지 못함
트랜스포머(Transformer)20일 전체를 한 번에 보며 어느 날끼리 관련 있는지 점수를 매김멀리 떨어진 날 사이의 관계도 파악자료가 적으면 외워 버리기(과적합) 쉽고 불안정

6. 향후 N일 예측 절차

  1. 시작일부터 N일의 날짜를 만듭니다. 토·일은 청구 없음(0건).
  2. 고른 모델로 평일 하루 총 건수를 예측하고, 기지×지역 비율로 나눕니다(0보다 작으면 0).
  3. 날짜별 합계(그래프), 수령지역·보급기지별 합계(표, 지도 원 크기)로 보여 줍니다. 그래프의 회색 선은 데이터의 최근 실제 건수입니다.

7. 전통적인 예측 방법 (본 프로그램에서는 사용하지 않음)

방법원리장점단점
이동평균최근 며칠의 평균을 다음 날 값으로 봄매우 단순, 이해 쉬움추세·계절 변화에 늦고, 지역·기지 정보를 함께 못 씀
지수평활최근 값일수록 더 큰 비중을 둔 평균(홀트-윈터스는 추세·계절 추가)단순·빠름급변에 늦고 범주 정보 결합이 어려움
자기회귀누적이동평균(ARIMA)과거 값과 과거 오차를 직선 관계로 묶어 예측통계적 근거, 신뢰구간 제공계열마다 따로 만들어야 하고 복잡한 관계에 약함

8. 이렇게 만든 이유

  • 데이터 규모: 1년치(평일 약 260일) 정도라 모델을 작게 유지했습니다. 자료가 적으면 단순한 모델이 이길 수도 있어서 네 모델을 같은 조건에서 비교합니다.
  • 가벼움: 추가 설치 없이 빠르게 학습·예측해 프로그램이 작고, 인터넷 없는 내부망 PC에서도 동작합니다.
  • 웹 확장: 같은 계산 결과를 웹 화면에서도 그대로 보여 줍니다.

실제 데이터가 쌓이면 같은 비교 방법으로 모델을 다시 고르는 것이 다음 단계입니다.
